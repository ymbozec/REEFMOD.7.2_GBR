# Notes: 
Running the model with the new coral connectivity (1 km resolution) requires the file GBR1_CONNECT.mat (~100 MB).
This file exceeds GitHub’s size limit and is therefore not included in the repository.
Please email me (y.bozec@uq.edu.au) to obtain a copy.

Running the climate projections requires the folder /Climatology/Future/CMIP6 which can be found in the repository [REEFMOD.7.0_GBR](https://github.com/ymbozec/REEFMOD.7.0_GBR)
